# 飞轮 SaaS 产品功能全景

飞轮笔记是一套围绕小红书内容生产设计的工作台。它把业务资料、选题研究、AI 创作、稿件管理、日历安排和发布衔接起来，同时通过 Skill API 向外部 AI 工具开放部分创作能力。

[返回首页](../README.md) · [快速开始](quickstart.md)

## 从业务资料开始

飞轮笔记的素材库用于保存创作时需要反复使用的信息：

- **产品档案**：产品或服务的基本信息、卖点、案例和视觉资料。
- **行业洞察**：用户问题、需求、信任与行业研究记录。
- **内容洞察**：标题公式、内容结构、优先方向与表达方法。
- **人设 IP**：账号面向的读者及表达方式。
- **知识库**：后续创作需要查阅的业务知识。
- **视觉素材**：招牌、实拍、风格和其他图片资料。

这些资料服务于后续选题、写作和出图，减少每次重新描述业务的重复劳动。实际引用范围以当前行业、产品和页面设置为准。

## 功能模块

### 发现首页：找到值得写的方向

发现首页用于浏览行业内容、热门笔记和选题灵感。它适合作为创作前的研究入口，帮助你从当前行业内容中筛选方向，而不是直接复制别人的笔记。

### 内容策略：明确每篇内容的任务

内容策略把行业洞察、内容方向和每周节奏放在一起：

1. 通过行业研究理解用户为什么关心。
2. 通过内容洞察管理标题、结构、重点方向和表达方法。
3. 通过周模板安排不同类型内容的节奏。
4. 到日历中确认实际排期。

策略用于指导后续内容计划，不会替代你对具体稿件的判断。

### 竞品监控：研究同行与参考内容

竞品监控支持：

- 按当前行业搜索、采集同行内容。
- 添加作者并跟踪账号更新。
- 查看每日动态、账号笔记与互动数据。
- 选择参考笔记进入仿写或导入稿件流程。

参考内容用于研究和再创作，发布前仍需检查事实、版权、平台规则和自身业务适配性。

### 日历：先安排，再制作

日历提供月、周和列表视图，并区分内容日历与选题库：

```text
设置内容规则
→ 添加或挑选选题
→ 安排日期
→ 加入稿件
→ 出图与审稿
→ 确认发布
```

把内容加入稿件不会自动出图或发布。制作费用会在后续操作中确认，日历出图等能力还可能受当前套餐权限影响。

### 写笔记：与 AI 完成图文创作

写笔记是飞轮的 AI 创作入口，围绕一个创作任务逐步完成：

- 明确主题、角度、读者和标题方向。
- 生成大纲、发布正文与分页内容。
- 检查并修改文案。
- 确认后生成整篇配图。
- 继续查看和管理生成的 record 与稿件。

公开 API 对外提供其中部分标准化能力；网页产品还包含资料、策略、日历、素材和发布等更完整的工作流。

### 稿件：集中制作与审核

稿件用于管理不同制作状态的内容，包括待生成、生成中、待审、已采纳和已发布。你可以在这里继续制作、检查文案与图片，并将确认后的内容衔接到发布流程。

### 发布：账号、助手与队列

发布功能包含：

- 绑定小红书账号并选择人设。
- 下载、连接和检查本机发布助手。
- 查看待执行、执行中、成功、失败或取消的任务。
- 在稿件中选择账号并进入发布流程。

暂时不使用发布助手时，也可以打开稿件，复制文案、下载图片后手动发布。账号绑定和自动发布权限以当前套餐及页面提示为准。

发布前应自行确认内容合法、真实、符合平台规则。工具不承诺曝光、互动或收益结果。

### Skill API：接入自己的 AI 工具

Skill API 适合需要自定义工作流的用户：

- 使用 Agent Skill 让 AI 工具完成创作调用。
- 使用 MCP 获得标准化的工具列表。
- 直接通过 HTTP 接入自己的后端服务或自动化系统。

公开能力包括健康检查、余额与流水、选题、大纲、改稿、出图、记录和稿件查询。完整网页产品的素材、日历、竞品和发布管理不等同于全部开放为公开 API。

## 两种使用方式

| 使用方式 | 适合人群 | 主要入口 |
| --- | --- | --- |
| 飞轮网页 SaaS | 创作者、运营与内容团队 | 发现、策略、写笔记、稿件、日历、素材和发布 |
| Skill API / MCP / HTTP | 开发者、AI 工具用户与自动化团队 | 选题、大纲、改稿、出图和记录查询 |

两种方式可以组合使用。例如，在网页中维护业务资料和稿件，在外部 AI 工具中通过 API 完成指定创作任务。

## 推荐的第一条使用路径

1. 注册并选择行业。
2. 完善一个产品或业务档案。
3. 在发现首页或竞品监控中确定一个参考方向。
4. 在写笔记中完成一篇内容，或先通过日历安排选题。
5. 在稿件中检查文案和配图。
6. 根据需要下载内容手动发布，或配置账号与发布助手。
